Задание 2. Рисунок CSS

Цель задания — нарисовать картинку размером 200×200 пикселей только средствами CSS, без графических файлов. Все предметы собраны из блоков div: стулья, столик, рамка с картиной, солнце и чайник. Форма деталей задана через border-radius и рамки, объём и цвет — через градиенты linear-gradient и radial-gradient, расположение — через абсолютное позиционирование и z-index.
